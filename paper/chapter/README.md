# Kapitel
Hier sollten die Kapitel gespeichert werden. In dieser [Datei](../04_Kapitel.tex) werden diese in das Dokument eingebunden.

Die vorhandenen Dateien sind eine mögliche Struktur. In diesen sind Beispielnutzungen, diese können gelöscht werden. Wenn die Kapitel nicht genutzt werden möchte, können diese auch gelöscht und bearbeitet werden. Es sollte in der Datei 04_Kapitel.tex die nicht genutzten Kapitel ausgetragen (auskommentiert) werden.
