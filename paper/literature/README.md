# Literatur
In der Datei [Literatur.bib](Literatur.bib) müssen die Literatureinträge gespeichert werden. Es können externe Tools z.B. Citavi genutzt werden. Die exportierte Datei muss `Literatur.bib` genannt und in diesem Ordner gespeichert werden.

Es gibt Bibtex-Generatoren als Website z.B. [citationmachine.net](https://www.citationmachine.net/apa) dort sollte vor dem Kopieren der Bibtex Style eingestellt werden
