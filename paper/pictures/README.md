# Bilder
Hier sollen Dokumente und Bilder abgelegt werden die mit dem Befehl `\bild{}{}{}` eingebunden werden. Es können einige Formate genutzt werden z. B. pdf, jpg, png. Zum Einbinden einzelner Seiten aus einem PDF Dokument sollte der Befehl `\\includepdf[options]{pdf-file}` genutzt werden.
```latex
\bild{#1 Groesse}{#2 Dateiname}{#3 Bildunterschrift}
```
